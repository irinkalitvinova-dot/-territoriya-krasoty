# Бренд «Территория красоты» (демо-шаблон парикмахерской)

Демонстрационный шаблон для портфолио. Название, адрес, телефон и цены вымышлены. Перед показом реальному заказчику меняем название, тексты, цены, контакты и фото.

## Идея
Название про «территорию», поэтому главный образ сайта — план парикмахерской с двумя залами: мужским и женским. Нажмёшь на зал, видишь его цены. Фоновые линии похожи на линии рельефа на карте.

## Логотип
`logo.svg` — метка на карте внутри тёмного квадрата, под ней линии рельефа.

## Цвета
| Название | Код | Где используем |
|---|---|---|
| Глубокий сине-зелёный | `#14313A` | текст, рамки, тёмные блоки |
| Прохладный белый | `#F1F4F3` | фон страницы |
| Шалфей | `#A9C4B5` | мужской зал, линии рельефа |
| Светлый шалфей | `#DCE6E1` | плашки, заливки |
| Малина | `#C2305F` | кнопки и главный акцент (текст на ней белый) |
| Розовая дымка | `#F3D3DE` | женский зал |
| Янтарь | `#F0B445` | мелкие значки |
| Белый | `#FFFFFF` | карточки |

## Шрифты
- Заголовки: **Unbounded** (широкий геометрический, с кириллицей).
- Текст: **Onest** (400, 500, 600, 700, с кириллицей).

Оба бесплатные, подключены в `brand.css` через Google Fonts.

## Голос
Простыми словами, на «вы», коротко. Без обещаний, которые нельзя проверить.

## Фото
В макете фото нет. Для реального клиента берём бесплатные стоки (Unsplash, Pexels, Pixabay) или фото работ самого салона. Лицензию проверяем на сайте источника.
